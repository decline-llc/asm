## 1. 用途、场景与局限

- **用途**：Hidden parameters discovery suite（Rust）；通过**逐行页面比对 + 响应码比对 + 反射检测**实现高准确率，能发现 `admin=true` 类非随机值参数。
- **适用场景**：对确认的 Web 端点做隐藏参数发现；与 arjun 互补（见下）。
- **局限**：主动发包，需授权；发现的参数是**线索**，需业务复核。`--learn-requests` 先发学习请求建立基线。
- **接入状态**：未安装；无调度。

## 3. 输入准备与场景命令（官方 README，待核对）

- **输入**：`-u/--url`（多 URL、URL 列表文件、自定义注入点 `%s`）；`-r/--request` 读 raw HTTP 请求文件（配合 `--proto`、`-p/--port`）；`-w/--wordlist` 参数字典（留空读 stdin）。
- **输出**：`-o/--output <file>`（`--append` 追加）；`-O/--output-format`：`standart, json, url, request`；`--save-responses` 存请求/响应；`--remove-empty` 跳过空结果。
- **关键参数**：`-c` 每 URL 并发（默认 1）、`-W/--workers` 并行 URL 数（`-W0` 全并行）、`--one-worker-per-host`、`-d/--delay` 毫秒、`--timeout`（秒，默认 15）、`-X/--method`（多值 GET POST…）、`-b/--body`（`{"x":{%s}}` 模板，支持 `{{random}}`）、`-t/--data-type`（urlencode/json，可自动检测）、`-m/--max`（每请求最大参数：query≤256/headers 64/body 512）、`-H` 自定义头（`Cookie: %s` 头值注入）、`--headers`（header 发现模式，自动剔除 Content-Length/Host）、`--param-template`（%k/%v，如 `user[%k]=%v`）、`--encode`、`-j/--joiner`、`--learn-requests`（默认 9）、`-x/--proxy`、`-B`（=`-x http://localhost:8080`）、`--replay-proxy`/`--replay-once`、`--recursion-depth`、`--verify`、`--reflected-only`、`--strict`、`-L/--follow-redirects`、`--mimic-browser`、`--invert`、`--check-binary`、`--force`、`--custom-parameters`/`--custom-values`（默认含 admin/debug/test 等及 1/0/true/false 等值）、`-v`（0/1/2）。

## 5. 与 arjun 的差异（官方 README 对比）

| 维度 | x8 | arjun |
|---|---|---|
| 实现 | Rust | Python |
| 判定 | 逐行页面比对+响应码+反射，高准确率 | 内置约 2.5 万大字典，50–60 请求 |
| 特色 | 模板/注入点定制、header 发现、递归、回放验证、海量 URL 并行 | 被动参数提取、Burp 导入导出 |
| 速度 | 依模板/并发 | 宣称 10 秒内一轮 |

两者均为 HTTP 隐藏参数发现，可互补使用。
